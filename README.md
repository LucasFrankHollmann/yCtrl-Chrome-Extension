# ytOverseer
Chrome extension to control YouTube tabs: play/pause, volume, speed and picture-in-picture for every open tab, from a single popup.

- Tested on Opera GX.

## Installation
- Clone this repository
- Run `npm install` and then `npm run build`
- Go to your browser's extensions page (```opera://extensions``` on Opera GX, ```chrome://extensions/``` on Chrome)
- Activate developer mode
- Select the "Load Unpacked" option
- Select the `dist` folder generated by the build

## Development
- `npm run build` — typecheck and build into `dist`
- `npm run build:watch` — rebuild on change
- `npm run icons` — regenerate the manifest icons from `branding/icon.svg`
- `npm run pack` — build and zip `dist` for a Chrome Web Store upload
